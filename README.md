# Machine Learning Coursework

Weekly exercises, notebooks, and a final presentation from a Data Science / Machine Learning course, covering NumPy/Pandas fundamentals, exploratory data analysis, and classification workflows on public datasets.

## Contents

| Path | Description |
|---|---|
| `exc1.py`, `exc2.py` | NumPy warm-up exercises (array statistics, set operations). |
| `w2-exc1.ipynb`, `w2-exc2.ipynb` | Week 2 exercises — boxplots and scatter plots. |
| `EDA/` | Exploratory data analysis on the Titanic dataset (`train.csv`, `test.csv`, `gender_submission.csv`). |
| `w3-exc1/` | Week 3 exercise using heart disease and oxygen saturation data. |
| `w4/` – `w8/` | Weekly classification/analysis exercises, mostly built around the heart disease dataset (`heart.csv`). |
| `presentation/` | Final presentation (`presentation.pdf`) and supporting notebook. |
| `rsi.py` | Standalone script that computes the Relative Strength Index (RSI) technical indicator from OHLC price data. |
| `exc.ipynb` | Additional exercise notebook. |
| `Iran.Khodro.csv` | Historical stock price data for Iran Khodro, used with `rsi.py`. |
| `diabetes.csv`, `student-dataset.csv` | Datasets used across various exercises. |

## Tech stack

- Python
- NumPy / Pandas
- Jupyter Notebooks
- matplotlib / seaborn (EDA and visualization)
